## Quick Start

本插件已上架 [插件市场](https://github.com/KarinJS/plugins-list)，在 Karin WebUI 插件市场中搜索 **`karin-plugin-kkk`** 即可快速安装。

## 诊断解析 API

为排查“开发态能跑、安装包实际运行不一致”这类问题，现在额外提供一组长期保留的诊断接口：

```text
POST /api/kkk/v1/platforms/<platform>/parse-by-url
```

当前覆盖：

- `douyin`
- `bilibili`
- `tiktok`
- `kuaishou`
- `xiaohongshu`
- `heybox`
- `x`
- `github`
- `zhihu`
- `tieba`
- `wechat`
- `weibo`

请求体支持：

```json
{
  "input": "原始分享消息或链接"
}
```

返回内容会包含：

- 平台归一化后的 `extractedUrl`
- 解析用 `idData`（敏感 cookie / token 已脱敏）
- `parsedPost`
- 轻量 `contentSummary`
- 不触发真实媒体下载的 `replySummary`
- 缓存命中与分阶段耗时

## 安装包 Smoke

如果你想在开发机直接验证“tgz 安装后的真实运行链路”，可以先打包，再执行：

```bash
pnpm --filter karin-plugin-kkk run smoke:pack -- --changed
```

常用方式：

```bash
# 全平台
pnpm --filter karin-plugin-kkk run smoke:pack -- --full

# 只测指定平台
pnpm --filter karin-plugin-kkk run smoke:pack -- --platform douyin,weibo

# 指定 tgz
pnpm --filter karin-plugin-kkk run smoke:pack -- --tgz /path/to/karin-plugin-kkk-4.0.26.tgz
```

说明：

- 默认会创建一个临时 Karin 运行目录，安装 `node-karin + tgz` 后再起服务
- 请求走真实 HTTP 签名链路，而不是直接调源码函数
- 除 B 站外，其余平台默认走游客 Cookie / 公网能力；B 站样例在没有显式 Cookie 时会跳过
- 可通过 `KKK_SMOKE_COOKIE_BILIBILI`（或 `BILIBILI_COOKIE`）这类环境变量给对应平台补 Cookie

## 自动更新（PM2 + tgz）

如果你的生产端不是直接 `pnpm app` 常驻，而是交给 PM2 托管，现在可以把插件包更新也自动化掉：

1. 先让 Karin 主进程跑在 PM2 下。`node-karin` 自带 `pm2.json`、`karin pm2`、`karin rs`，插件内调用的 `restartDirect()` 在 `RUNTIME=pm2` 时也会走 PM2 重启链路。
2. 在生产机额外启动一个 sidecar：

```bash
pnpm exec kkk-auto-update --release-dir /path/to/releases --runtime-dir /path/to/karin
```

3. 每次开发机打包出新的 `karin-plugin-kkk-<version>.tgz` 后，只要把文件放进 `--release-dir` 指向的目录，sidecar 就会：
   - 找出目录里版本最高的 tgz
   - 在 `--runtime-dir` 中执行 `pnpm add <tgz>`
   - 安装成功后执行 `pnpm exec karin rs`
   - 把已成功应用的版本写入状态文件，避免重复安装

常用参数：

```bash
pnpm exec kkk-auto-update \
  --release-dir /path/to/releases \
  --runtime-dir /path/to/karin \
  --interval-ms 10000
```

- `--once`：只扫一次，适合手动验证
- `--state-file`：自定义状态文件位置
- `--watch-dir`：`--release-dir` 的别名

建议把主进程和 sidecar 都交给 PM2：

```bash
pnpm exec karin pm2
pm2 start "pnpm exec kkk-auto-update --release-dir /path/to/releases --runtime-dir /path/to/karin" --name kkk-auto-update
```

也就是：Karin 主进程继续用它自带的 `@karinjs/config/pm2.json`，sidecar 单独常驻；这样插件自身的“已安装新版本后自动重启”和外部 tgz watcher 可以共存，谁先发现新版本都不冲突。
